明末杀 · 手机玩法
================

一、电脑端
1. 解压整个压缩包到电脑。
2. 在解压后的文件夹打开 PowerShell。
3. 如果电脑有 Python，执行：
   python -m http.server 8080
4. 执行 ipconfig，找到电脑的 IPv4 地址，例如 192.168.1.23。
5. 第一次运行如果 Windows 防火墙弹窗，选择“允许访问”。

二、手机端
1. 手机连接同一个 Wi-Fi。
2. 用 Chrome / Safari / Edge 打开：
   http://电脑的IPv4地址:8080
   例如：http://192.168.1.23:8080
3. 打开后，浏览器菜单选择“添加到主屏幕”，以后可直接全屏进入。

三、没有电脑时
把整个文件夹上传到 Netlify Drop、GitHub Pages、Vercel 等静态网站，
得到一个网址，手机打开网址即可。
注意：必须上传整个文件夹，assets、css、js 不能漏。

四、安卓本地打开
用解压工具解压后，用 Chrome / Edge / Firefox 打开 index.html。
部分浏览器会限制本地文件夹读取，若页面空白或缺图，请改用第一或第二种方式。
不要点 start-game.bat，它只适用于 Windows。

五、操作
点手牌选中，再点“使用”；响应时选择可打出的【闪】【桃】【无懈可击】。
点武将技能查看说明；点“结束回合”进入下一回合。
1V1 / 1V2 竖屏可玩；1V5 建议横屏。
第一次点击页面后才会播放背景音乐，这是手机浏览器的自动播放限制。

六、注意
当前牌局刷新即重开，没有云存档。
成就与设置保存在当前手机浏览器；清理浏览器数据会重置成就。
微信内打开链接时，建议选择“在浏览器中打开”。
