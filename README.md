# 明末杀 · MING MO SHA

基于《饿殍：明末千里行》与《哀鸿：城破十日记》的同人 1V1 / 1V2 / 1V5 卡牌游戏。纯前端、无依赖、无需安装，直接用浏览器打开即可游玩。

**作者：广开兮穗门**

**当前版本：Ver.0.90**

> 饿殍千里，城破十日。牌局之上，只活一个。

## 开始游戏

- 双击 **`start-game.bat`**；或
- 直接用现代浏览器打开 **`index.html`**。

推荐使用 Edge / Chrome / Firefox 桌面版；也适配了手机竖屏。游戏进度只存在当前页面内，刷新即重开。

## 玩法

- 选择一名武将，与人机进行 1V1 对局；也可切换为 1V2 或 1V5。
- 回合流程：判定 → 摸牌 → 出牌 → 弃牌。
- 1V1 将对手体力降至 0 且无人救援即可获胜；1V2 需要击败两名对手；1V5 需要击败五名对手。
- 1V5 使用座次距离：你与五名对手围成一圈，距离决定【杀】能否命中；武器提供攻击范围。赤兔令你计算距离-1；爪黄飞电、的卢、绝影令别人计算与你的距离+1。角色死亡后会从座次中移除，存活角色按剩余人数重新计算距离。
- 1V5 中你每回合摸牌阶段额外摸 2 张，每回合【杀】的使用次数 +1。
- 新增【雷杀】【火杀】属性杀；新增防具【藤甲】【布衣】【八卦阵】与防具栏。
- 每局结束再战时，敌人会更换为不同的武将；如果手动指定了对手阵容，则再战会保留该阵容，“全随机”模式才会自动更换。
- 点击手牌查看可用性，再点击“使用”；需要响应时，会弹出可打出的牌。
- 点击武将牌上的技能名查看完整说明；发亮的技能可以在出牌阶段主动发动。
- 【过河拆桥】【顺手牵羊】可以指定对手的**手牌区或装备区**：手牌仍是背面选择、结算后才揭示；装备区的武器则公开可选。
- 【无懈可击】可以在锦囊生效前打出抵消它；对手也能再用【无懈可击】反制，双方轮流结算。
- 1V2 中单体牌会先弹出目标选择；【南蛮入侵】【万箭齐发】会同时结算两名对手。
- 武器牌进入武器栏后持续生效；换装时旧武器进入弃牌堆。
- 【酒】可多次饮用，每层令下一张【杀】伤害+1；濒死时也可当【桃】使用，回复1点体力。
- 手牌牌面带有从《哀鸿》游戏 CG 裁切的原画；不同牌名使用不同画面。
- 人机强度分为“初入乱世 / 江湖老手 / 十死无生 / 超级困难”四档；超级困难会完整响应、优先斩杀并像熟悉规则的人类一样保留关键牌。
- 主页“作弊模式”可开启无敌、无限出牌、出牌不可响应，并调节伤害倍率（1×~1000×）与额外伤害（+0~+100000）；提供“一刀十万”预设，设置保存在本机。
- 选将页可点击“选择对手”，手动指定 1V1/1V2/1V5 的敌方武将，也可选择“全随机”。指定不足的席位由系统随机补足。

### 音效与动效

- 卡牌打出、抽牌、挥刀命中、闪避、桃回复、判定翻牌、技能发动、回合与胜负都有独立音效。
- 环境声由 WebAudio 实时合成：低音弦、纸雨与偶尔的古琴拨弦；可在对局右上角切换“声 / 静”。
- 对局右上角的“量”是调试音量入口：可拖动主音量、试听【杀】/【闪】、恢复 100%，设置保存在本机。
- 整体音量已提高，并在输出端加入限幅器防止爆音。
- 【杀】使用低频撞击 + 金属破风 + 皮肉撕裂/湿响 + 下沉长尾的厚重音色；【闪】使用高频扫频的“破空”whoosh，并带残影出现时的空气尾音。
- 每种牌名都有独立的牌名印记、色调、粒子与音效：【杀】斬红、【闪】避青、【桃】生粉、【酒】醉琥珀、【无中生有】無金、【过河拆桥】拆钢、【顺手牵羊】牽金、【决斗】決红、【南蛮入侵】蠻褐、【万箭齐发】箭银、【乐不思蜀】樂紫、【兵粮寸断】糧赭、【无懈可击】懈银，以及刀/劍/弓三张武器的金属声；响应打出的【闪】【桃】【酒】【无懈可击】也会触发对应特效。
- 【杀】出手有挥砍轨迹，命中时追加刀锋横斩、斩痕、血弧、大块血溅、飞散血滴、冲击环、“殺”字与墨点，并触发震屏；闪避出现残影；桃回复飘落花瓣；判定牌翻面；觉醒与技能发动有金色字效。
- 造成伤害时按伤害量分级反馈；玩家受伤会触发红屏、屏幕血迹、刀痕与刀割音效。2点以上重击追加全屏红闪、冲击环、飞散碎屑、重低音、震屏和加大的伤害数字，并延长命中停顿。
- 所有音效均为代码实时合成，没有外部音频文件；桌面与手机通用。

## 一挑二 / 一挑五

- 选将页可选择 **1 V 1 / 1 V 2 / 1 V 5**。
- 1V2 中，你独自面对两名随机人机；1V5 中面对五名。
- 多名对手依次行动，均以你为目标；单体牌会先弹出目标选择，【南蛮入侵】【万箭齐发】会命中全部对手。
- 1V5 专属：座次距离、武器攻击范围、进攻/防御坐骑栏、赤兔/爪黄飞电/的卢/绝影四张坐骑牌。
- 1V5 专属加成：每回合多摸 2 张牌，【杀】次数 +1。
- 击败全部对手才算胜利；被任意一名对手击倒即失败。

## 成就

- 首页标题下方有成就栏，显示已解锁数量与最近成就；点击可查看全部 47 个成就。
- 成就记录保存在本机浏览器；换浏览器或清理站点数据会重置。
- 成就包括首胜、1V2/1V5 胜利、满血胜、1 血胜、5 回合速胜、单局伤害/摸牌/技能/回复/装备、双坐骑、三模式、使用 10 名武将、3 连胜，以及多位武将胜利、50局、40点伤害、5连胜、超级困难胜利等；其中“神憾”首次达成会触发全屏双将立绘、墨浪与金红神光特效。
- 完成对局结算时自动判定并弹出解锁提示。
- 成就弹窗底部有“重置成就”按钮，确认后会清空全部成就与统计。

## 击杀成就全屏演出

- 26个击杀成就均有独立全屏演出，配置位于 `js/killfx.js`。
- 每套配置包含：主题色、纹样字符、标题、副标题、背景模式与专属字符雨。
- 模式包括：墨、刀、火、花、纸、潮、金、雷、雪、旧梦。
- 连续解锁多个击杀成就时，演出会排队依次播放，不会互相覆盖。
- 所有击杀成就解锁时同时弹出金色提示卡并播放成就音效。

## 牢方专属语音

- `assets/audio/laofang-zakou.mp3`：牢方使用主动技能，或使用/打出任意牌时播放。
- `assets/audio/laofang-oniichan.mp3`：牢方触发被动（杂鱼、尼酱十位变化），或技能被挡/不可用时播放。
- 仅牢方拥有这套语音，其他武将不会触发。
- 语音跟随音效音量与静音开关；同名语音有700ms防刷屏间隔。

## 历史战绩

- 首页导航新增「战绩」入口。
- 自动记录完成对局的胜负、己方武将、对手、模式、难度、回合、伤害/技能/回复/出牌。
- 支持全部、胜利、失败筛选。
- 支持删除单条记录，以及两次点击确认清空全部。
- 记录最多保留100局，仅保存在当前浏览器 localStorage。

## 背景音乐

- 自动模式按场景切换三首曲目：
  - 主页与选将：**Redemption of the Wolf**（06）。
  - 牌局：**Li's March**（01）。
  - 自身只剩 1 点体力：**Daggers Drawn**（08）；回复到 2 点以上切回牌局曲。
- 右上角“乐”或主页“音律”打开设置：自动、主页面、战斗、濒危、本地五种模式，独立音乐音量，以及本地 MP3 / WAV / OGG / M4A 导入。
- 导入文件通过 IndexedDB 保存在本机浏览器；如浏览器清理站点数据或更换浏览器，需要重新导入。
- 音效开关会同时暂停/恢复背景音乐；音乐音量与音效主音量分别保存。
- 三首曲目文件由用户提供，转为 22.05kHz 单声道 WAV 内置，仅用于本作本地非商业展示。

## 彩蛋

- **医术高超**：同一回合内连续使用 3 张【桃】。
- **酒醉万世**：同一回合内连续饮用 3 张【酒】。
- **癫狂屠戮**：单次造成至少 3 点伤害。

触发时会出现全屏炸裂特效、专属重低音，并通过浏览器中文语音播报彩蛋名称。每个彩蛋有多套口语化台词，随机选择并调整语速、音高与重音，尽量读得像活人而不是播报器；语音使用系统 SpeechSynthesis，若设备没有中文语音包，视觉与音效仍会正常触发。

### 牌堆（164 / 168 张）

- 原 72 张基础牌整体复制为两份，共 **144 张**（新增丈八蛇矛）。
- 追加属性杀：雷杀 ×4、火杀 ×4。
- 追加防具：藤甲 ×2、布衣 ×2、八卦阵 ×2。
- 追加【酒】×6，酒的总数提升到 12 张。
- 常规牌堆 **164 张**；1V5 另外追加 4 张坐骑牌，共 **168 张**。
- 武器牌：良的朴刀（范围2）、王生的长剑（范围2）、妖兵的角弓（范围3）、丈八蛇矛（范围3；可弃一张手牌令本张杀不可闪）。
- 伤害反馈：普通伤害为面板震动与低音；2点以上伤害追加全屏红闪、冲击环、碎屑、重击数字与震屏。
- 自身仅剩1点体力时，屏幕边缘出现血迹、滴血与红光；濒死时扩大增强；死亡时追加大量血迹与深红暗角。

李闯王：
- 【闯王】：出牌阶段限一次，你打出的牌无法被响应且结算效果翻倍。发动后只强化本回合打出的下一张牌；伤害、回复、摸牌、拆/顺牌数、延时锦囊时长与武器特效都会翻倍，目标不能打出【闪】【杀】或【无懈可击】响应。
- 【席卷】：锁定技，你每使用一张牌后摸一张牌，每回合限两次。
- 【百战】：锁定技，每回合限一次，当你受到伤害后，若体力值不大于2，回复1点体力。

新增四位《饿殍》角色与一位《哀鸿》角色：
- 【舌头】巧舌：弃一摸二，黑色牌再令对手随机弃牌；油滑：每回合一次，弃一牌令【杀】无效。
- 【琼华】矜贵：每回合第一次受伤减1；诗书：摸二弃一。
- 【红儿】辣手：使用【杀】造成伤害后摸牌，目标手牌更多时摸两张；护妹：受伤后若手牌少于体力，摸一张。
- 【翠儿】采薇：摸一牌，若为红色回复1点；依偎：受伤后摸一张。
- 【心兰】照影：成为【杀】目标时摸一张；心兰：弃一牌，回复1点并摸一张。
- 【金翅大鹏王】鹏程：计算与其他角色的距离-1；吞日：弃一牌，对攻击范围内一名角色造成1点伤害，若其体力不大于你则摸一张。
- 【豚妖】泥淤：其他角色计算与你的距离+1；贪食：每回合一次，你使用【杀】造成伤害后摸一张。

蓝色大肥鱼：
- 体力上限 3，称号深度求索；DeepSeek 娘化形象的彩蛋武将。
- 【算力】：锁定技，摸牌阶段多摸1张，手牌上限+1；每回合首次使用锦囊后摸1张。
- 【求索】：出牌阶段限一次，观看牌堆顶4张，获得其中2张，其余置底；两张类型不同则再摸1张。
- 【深潜】：限定技，首次濒死时回复至3点体力、摸3张，重置【求索】且下次求索多拿1张。
- 【干饭】：锁定技，摸牌后获得1枚“大白饭”（Token），每回合最多2枚，上限6枚。
- 【暴食】：出牌阶段限一次，消耗3枚大白饭摸2张回1；若消耗前有6枚，改为消耗6枚摸3张回1并重置求索。
- 【梁圣赐饭】：锁定技，大白饭上限+2（8枚）；每回合首次获得大白饭额外+1。名称与设定为游戏内玩梗，关联 DeepSeek 创始人“梁圣”的网络称呼。

牢方：
- 体力上限3，称号抽象芳容，第二十四位武将。
- 【猎奇】：出牌阶段限一次，观看牌堆顶8张并调整顺序，然后依次使用前X张，X=体力值+手牌数。
- 【杂鱼】：限定技，进入濒死时回复Y点体力（Y=本局进入濒死次数），对一名角色造成Y点雷电伤害，获得【尼酱】【萝莉】。
- 【尼酱】：使用或打出一张牌后获得等于点数的“妈”；“妈”的十位数每变化一次，获得一张点数等于新十位数的牌。
- 【萝莉】：出牌阶段限一次，弃一张基本牌，所有其他角色各进行“妈”个位数次闪电判定。

忘忧：
- 体力上限5，开局2点体力；称号吸血之鬼。
- 【吸血】：锁定技，开局1枚“狂”；杀造成伤害后按狂的数量回复体力。
- 【嗜血】：锁定技，桃视为酒；受到火杀伤害+1。
- 【血魔】：出牌阶段限两次，扣体力上限回等量体力，或扣体力提高等量上限。
- 【护身】：受伤时若体力未满，可扣等量体力上限并摸1张；因此损失的体力化为狂。
- 【不屈】：濒死判定新花色则记录并免死；打出已记录花色的牌时移除记录。

满禾：
- 体力3，称号穗禾良缘；开局3枚缘，每使用/打出一张牌+0.5缘。
- 【穗锁】：消耗1缘封存一名角色一张手牌进余生区；其他角色每被封印一张，体力上限永久-1（最低1）。
- 【余生】：准备阶段若余生区有牌，弃置判定区所有牌。
- 【良缘】：出牌阶段限两次；余生1~3封技，4~6清空手牌装备，7+直接索命。
- 【执念】：准备阶段余生≥5觉醒；每回合选择免缘交换、跳过摸牌无敌、或伤害+2跳弃牌。
- 立绘使用用户提供的蓝色鱼娘原画，完整人物、鱼尾与深海配色。

常宣灵：
- 体力上限 3，称号穗语载福；拥有“叙”标记与叙事区。
- 【穗叙】：开局3枚叙；花1枚将一名角色一张牌移入叙事区（回合结束归还），然后摸1张牌或令其本回合不能出闪；每有一名角色阵亡获得1枚叙。
- 【途馑】：所有牌堆与弃牌堆合并为荒仓，所有摸牌从荒仓取；荒仓为空时，每个回合开始所有存活角色流失1体力。
- 【同路】：每回合限一次，绑定一名敌人，令其获得【饥】；其每打出一张牌须交给你一张手牌，持续到你的下回合。
- 【茶话】：回合结束若本回合有角色阵亡，可回溯一名存活角色的体力、手牌与装备到回合开始，然后摸2张牌；归程后可回溯上一回合。
- 【替灾】：限定技，选一名角色为锚点；你的伤害与回复转移给锚点，锚点累计承受3次转移后直接死亡。
- 【归程】：准备阶段若荒仓≤10张，觉醒；穗叙不再消耗叙，茶话可回溯上一回合，获得【断途】。
- 【断途】：出牌阶段限一次，消耗5枚叙，令一名角色直接死亡。
- 为适应无友方的 1V1/1V2/1V5，同路的友方分摊未实装；茶话暂限本回合/上一回合。
- 立绘使用用户提供的原画，仅用于非商业同人展示。

穗诗书生墨：
- 体力上限 3，开局满血；拥有“墨”标记与【简牍区】。
- 【诗书】：开局获得2枚墨，回合结束补1枚墨；失去墨时摸等量牌。可消耗1枚墨，将任意角色一张牌收入简牍区；简牍牌在回合结束时归还原主，可永久查看。
- 【诗人】：简牍区≥2张时，不能成为【杀】和单体锦囊的目标。
- 【断更】：出牌阶段弃置全部墨，令当前简牍牌永久保留，并跳过下一个出牌阶段；没有墨也可发动。
- 【神罚】：出牌阶段限一次，移出一张简牍牌，对一名角色造成1点伤害或令其流失1点体力；累计移出4张后，下一次神罚可直接令其死亡。
- 【神赐】：准备阶段若简牍区≥4张，觉醒获得【成神】。
- 【成神】：出牌阶段限一次，获得2枚墨，且神罚不再消耗简牍牌。
- 立绘使用用户提供的原画，仅用于非商业同人展示。

兮穗门：
- 体力上限 3，开局 2 点体力，初始手牌 2 张。
- 【封刀】：锁定技，不能使用或打出【杀】；【酒】的伤害加成可附加在伤害类锦囊上。
- 【遇穗】：摸牌阶段前可跳过摸牌，连续猜下一张牌点数大小；猜对则体力上限+1（最多10）或回复1点体力，并可继续；最后获得所有展示牌。
- 【仇视】：每回合限一次，造成伤害后可将手牌摸至体力值，或将体力回复至手牌数。
- 【穗门】：回合结束时若手牌与体力相差3以上，失去1点体力上限，获得【背水】，【仇视】在自己回合可发动两次。
- 【背水】：准备阶段若手牌或体力小于2，失去1点体力上限，获得【清剿】，【仇视】可在受伤后发动。
- 【清剿】：出牌阶段开始可弃光手牌，随机获得8张牌名与类别各不相同的牌；结束阶段弃置所有手牌。
- 【内伤】：锁定技，初始手牌为2。
- 【穗亡】：限定技，首次死亡时回复4点体力，只废除【仇视】，保留【清剿】；【封刀】改写为杀酒不限次数，除杀外的基本牌视为【杀】，锦囊牌可选择视为【酒】或【过河拆桥】。
- 立绘使用用户提供的原画，仅用于非商业同人展示。

王生：
- 【旧游】：出牌阶段使用的第一张牌结算前，摸一张牌。
- 【护家】：每回合首次受到伤害时，伤害-1；手牌上限+1。
- 角色定位为方知宥的同年旧友、乱世秀才，立绘取自《哀鸿：城破十日记》官方角色视频封面。

神·满穗：
- 体力上限 4，开局只有 2 点体力；立绘使用用户提供的原画。
- 【裂穹】：当你对其他角色造成伤害后，可击伤其一个部位：天冲（已击伤过才可选，失去当前体力，击杀加体力上限）、力烽（弃一半手牌）、地机（下次受伤+1）、中枢（下一张牌无效）、气海（封锁红桃牌）。
- 【斩决】：出牌阶段开始时二选一——摸当前体力张牌，本阶段下一张【杀】无距离限制且不能被【闪】响应；或摸已损失体力张牌，本阶段下一次造成伤害后回复等量体力。
- 【不灭】：限定技，进入濒死时回复至2点体力并摸一张牌，每局限一次。

界限突破良：
- 体力 4，阵营群。
- 【孤城】：准备阶段（判定阶段前）可选择改写本回合规则：出牌无距离、无【杀】次数限制，所有牌无法被响应，但至多使用 7-X 张牌；X为场上其他存活角色数，若X为偶数则翻倍，最少1张。
- 【死战】：造成伤害后摸一张牌；若场上其他存活角色数不少于3，改为摸两张。
- 不再按1V1/1V2/1V5模式给不同增益，全部按场上人数结算。

史可法：
- 体力 4，阵营明，扬州督师。
- 【势斩】：使用【杀】无距离限制，且不能被【闪】响应。
- 【狂骨】：对其他角色造成伤害后回复1点体力。
- 【死守】：每回合首次受到伤害时，伤害-1。
- 【殉国】：限定技，濒死时回复至2点并摸一张，每局一次。
- 技能参考势魏延的强命与以战养战；立绘使用用户提供的原画，仅用于非商业同人展示。
